Translation uses AI to translate ticket messages between your staff language and the customer's language, so your team can support people worldwide.

<Info>
  Ticket translation is an **Enterprise** feature. ModMail translation is available on **Pro** and higher. [Upgrade your plan](https://ticketcord.com/pricing) to access it.
</Info>

## How It Works

1. A message arrives in a ticket
2. The AI detects its language (when detection confidence is above the threshold, default 80%)
3. After the translation delay, the translation is posted according to the display mode
4. Staff replies are translated back when the mode allows it

## Settings

Open **Dashboard → Bots → your bot → Servers → the server → AI Features → Translation**.

### Mode

| Mode | Behaviour |
|------|-----------|
| **Auto-detect** (default) | Translate whatever is not in the staff language |
| **Customer to staff** | Only translate customer messages |
| **Staff to customer** | Only translate staff messages |
| **Bidirectional** | Translate both directions |

### Display

| Mode | Behaviour |
|------|-----------|
| **Embed replace** | A "🌐 Message Translation" card shows the original and the translation with language flags |
| **Reply preserve** | The bot replies with the translation; the original stays visible |
| **Smart auto** (default) | Embed for text-only messages, reply for messages with attachments |

The cards show the language codes and the text; no confidence score is displayed.

### Languages

Choose up to 20 languages: Arabic, Czech, Danish, Dutch, English, Finnish, French, German, Hindi, Italian, Japanese, Korean, Norwegian, Polish, Portuguese, Russian, Spanish, Swedish, Turkish, and Chinese. Ten are enabled by default: English, Spanish, French, German, Portuguese, Italian, Russian, Japanese, Korean, and Chinese. Set your **staff language** and a **fallback language**.

### Filters

Skip messages that do not need translating. All filters are on by default:

- Short messages (minimum length 5, 10 (default), 20, or 50 characters)
- Code blocks
- Commands
- Emoji-only messages
- Link-only messages
- Repeated phrases
- Custom patterns you define

### Timing and Quality

| Setting | Options |
|---------|---------|
| **Translation delay** | 5 to 60 seconds, default 5 |
| **Confidence threshold** | Default 65%; below it a low-confidence notification is sent instead |
| **Review threshold** | Default 40%; translations below it are flagged for staff review |
| **Max message length** | 500, 1,000, or 2,000 characters (default and maximum 2,000); longer messages are not translated |

### Notifications

Notify on each translation, on detection failure, or on low confidence, optionally in a dedicated channel.

## Staff Commands

Staff can turn translation on or off for one ticket with `/translation enabled:<True|False>`.
