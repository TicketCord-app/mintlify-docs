---

Priority Detection uses AI to analyze ticket content and assign a priority. Urgent issues get flagged early; routine questions stay at normal priority.

<Info>
  Priority Detection is a **Pro** feature (Pro and Enterprise). [Upgrade your plan](https://ticketcord.com/pricing) to access it.
</Info>

## How It Works

1. A user opens a ticket or sends a message
2. After the analysis delay, the AI reads the conversation for urgency signals
3. If its confidence is above your threshold, it assigns Low, Medium, High, or Urgent
4. The channel name gets a priority emoji and, for High and Urgent, a card is posted to your logs channel

| Priority | Emoji | Typical content |
|----------|-------|-----------------|
| **Low** | 🟢 | General questions, no urgency |
| **Medium** | 🟡 | Standard issues |
| **High** | 🟠 | Significant impact or frustration |
| **Urgent** | 🔴 | Time-sensitive, major impact (the AI calls this "critical" in its analysis) |

Channel names become `🔴-ticket-0001` and so on. Renaming is best effort: Discord allows two channel renames per 10 minutes, so the rename can be skipped while the priority is still recorded.

## Settings

Open **Dashboard → Bots → your bot → Servers → the server → AI Features → Conversation**.

| Setting | Options |
|---------|---------|
| **Analysis mode** | First message, first three messages, or smart detection (default) |
| **Delay before analysis** | Default 30 seconds. The bot always waits at least 30 seconds so rapid follow-up messages are included |
| **Confidence threshold** | 10% to 100%, default 70% |
| **Update channel name** | Add the emoji to the channel name (default on) |
| **Notify staff** | Post a detection card to the logs channel for High and Urgent tickets (default on; needs a logs channel) |
| **Override existing** | Replace a priority staff already set (default off) |
| **Auto-escalate high priority** | Raise an escalation for High and Urgent tickets |

## Working with Staff

Staff can always set priority by hand with `/priority level:<urgent|high|medium|low>`. With **Override existing** off, the AI never changes a priority a staff member set.

## Troubleshooting

### Priority is never set

Check the feature is enabled, the owner's plan is Pro or higher, and lower the confidence threshold.

### No notification arrives

Notifications go to the logs channel configured for the server; set one under **Structure**.
