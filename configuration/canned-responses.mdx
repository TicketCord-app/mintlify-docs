Canned responses (also called quick replies) are pre-written answers your staff send with `/reply`.

## Plan Limits

| Plan | Canned responses |
|------|------------------|
| Free | Not available |
| Basic | 25 |
| Pro | 25 |
| Enterprise | Unlimited |

## Creating a Response

Go to **Dashboard → Bots**, pick your bot, choose the server, and open the **Quick Replies** tab.

| Field | Limit |
|-------|-------|
| **Name** | Up to 100 characters |
| **Shortcut** | Up to 20 characters, stored in lowercase |
| **Content** | Up to 2,000 characters |
| **Category** | Optional, up to 50 characters, for grouping and filtering |

## Variables

Write variables as `{{name}}`. The older `{name}` form also works. Unknown variables render as empty text.

| Variable | Renders as |
|----------|-----------|
| `{{user}}` or `{{user.mention}}` | Mention of the ticket creator |
| `{{user.displayName}}` | Creator's display name |
| `{{user.username}}` | Creator's username |
| `{{user.id}}` | Creator's user ID |
| `{{ticket.number}}` | Ticket number |
| `{{ticket.id}}` | Ticket ID |
| `{{ticket.category}}` | Ticket category |
| `{{ticket.priority}}` | Ticket priority ("Normal" when none) |
| `{{ticket.createdAt}}` | Creation time as a Discord timestamp |
| `{{guild.name}}` | Server name |
| `{{guild.memberCount}}` | Server member count |
| `{{staff.displayName}}` | Display name of the staff member sending the reply |
| `{{staff.username}}` | Username of the staff member |
| `{{now}}` | Current date and time |
| `{{today}}` | Today's date |
| `{{time}}` | Current time |

Filters can be appended, for example `{{user.username|upper}}`, `{{ticket.createdAt|relative}}`. Available filters: `upper`, `lower`, `capitalize`, `date`, `time`, `relative`.

## Sending a Response

Inside a ticket, staff run:

```
/reply shortcut:refund
```

The `shortcut` option autocompletes from your saved responses. Only staff can use it; the Free plan cannot.

<Note>
  There is no text trigger such as `!refund`, and responses cannot be inserted from the dashboard reply box. `/reply` is the only way to send one.
</Note>

## Managing Responses

- Edit or delete responses from the same tab; search and filter by category.
- Each response shows how many times it has been used.
- Responses belong to one server. To reuse them elsewhere, create them again on the other server.
