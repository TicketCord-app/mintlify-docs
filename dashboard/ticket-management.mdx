**Dashboard → Tickets** lists every ticket across your bots.

## Finding Tickets

| Control | Options |
|---------|---------|
| **Search** | Free text, up to 100 characters |
| **Status** | Open, closed, deleted |
| **Priority** | None, low, medium, high, urgent |
| **Assignment** | Mine, unassigned |
| **Access** | Tickets from bots you own, or bots you manage as staff |
| **Bot** | Limit to one bot |
| **Tags** | Tickets must carry every selected tag |
| **Sort** | Created, updated, last activity (default), or priority |

Save a combination of filters as a **view** to reuse it.

## Ticket Page

Open a ticket to read the conversation, notes, and approval pane. The toolbar offers: Claim, Unclaim, Close, Reopen, Delete, Set priority, Rename, Add user, Remove user, Send transcript, and Export.

## Bulk Actions

Select several tickets to close, tag, untag, set priority, export, delete, or purge them. See [Bulk Operations](/features/bulk-operations).

## Transcripts and Exports

- Export a ticket as HTML, JSON, CSV, or PDF, in the default, compact, or detailed template. The file downloads immediately.
- Transcript pages at `ticketcord.com/transcripts/...` require signing in with a dashboard account that has access to the ticket.

## Deleting

**Delete** soft-deletes a ticket; it stays visible under the Deleted status. **Purge** permanently removes deleted tickets and is limited to the bot owner.

See [Keyboard Shortcuts](/features/keyboard-shortcuts) for `g` then `t` and the command palette.
