**Dashboard → Bots** lists your custom bots.

## Plan Limits

| Plan | Custom bots |
|------|-------------|
| Free | 1 |
| Basic | 3 |
| Pro | 3 |
| Enterprise | 6 |

## Adding a Bot

Click **Add Bot** and paste the bot token from the Discord Developer Portal. TicketCord validates it and reads the application ID and name from Discord. See [Installation](/bot/installation).

## Bot Status

| Status | Meaning |
|--------|---------|
| **Online** | Connected to Discord |
| **Connecting** | Starting up |
| **Offline** | Stopped |
| **Error** | Failed to start; see the error shown on the bot |
| **Token invalid** | Discord rejected the token; update credentials |
| **Plan limited** | Stopped because it exceeds your plan's bot limit |
| **Banned** | Disabled by TicketCord |
| **Deletion pending** | Being removed |

Each bot shows how many servers it is in and its gateway ping.

## Bot Settings

| Setting | Plan |
|---------|------|
| Custom status (playing, watching, listening, competing) | Basic+ |
| Remove the TicketCord footer | Basic+ |
| Custom footer text and icon | Enterprise |

## Updating the Token

Open the bot and choose **Update Credentials**. TicketCord generates a temporary update link where you paste the new token; the bot restarts with it.

## Restarting

Use **Restart** on the bot page. Bots start automatically after credential updates and plan changes.

## Transferring Configuration

**Transfer configuration** copies server configurations, canned responses, and bot settings from one of your bots to another.

## Deleting a Bot

From the Bots list choose **Delete**, type the bot name to confirm, and optionally leave all servers first. This permanently removes the bot and all associated data, including tickets, knowledge base, analytics, embeds, and server configurations.

## Error Codes

If your bot encounters issues, you may see error codes:

| Code | Meaning | Solution |
|------|---------|----------|
| TC001 | Rate limited by Discord | Wait a few minutes and retry |
| TC002 | Permission denied | Grant the bot or user the required permissions |
| TC004 | Resource not found | Recreate the missing channel, category, or role |
| TC011 | Configuration not found | Complete setup in the dashboard |

See [Troubleshooting](/bot/troubleshooting) for the full error code reference.
