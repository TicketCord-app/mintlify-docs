---
title: "Bulk Operations"
description: "Perform actions on multiple tickets at once"
---

Select several tickets on **Dashboard → Tickets** and act on all of them in one go.

## Selecting Tickets

Tick the checkbox on each ticket, or use the header checkbox to select every ticket visible on the page. The action bar appears at the bottom.

## Available Actions

| Action | Notes |
|--------|-------|
| **Close** | Optional close reason |
| **Add tag** | Tag up to 50 characters |
| **Remove tag** | |
| **Set priority** | None, low, medium, high, or urgent |
| **Export** | HTML, JSON, CSV, or PDF |
| **Delete** | Soft-deletes the tickets |
| **Purge** | Permanently removes deleted tickets; bot owner only |

Each action asks for confirmation in a dialog. You must own or manage every selected ticket.

## Limits

- Up to 100 tickets per update
- Up to 50 tickets per export, and up to 10 for PDF
- Tickets that could not be updated are listed with the reason after the operation

<Note>
  There is no bulk assign or move-to-category action. Claiming is done per ticket with `/claim` or the ticket toolbar.
</Note>
