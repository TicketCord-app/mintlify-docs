Press `?` anywhere in the dashboard to see this list.

## Global

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + K` | Open the command palette |
| `?` | Show the shortcuts help |
| `Esc` | Close the palette or help, or leave the current input |

## Navigation

Press the two keys one after the other, within one second.

| Shortcut | Goes to |
|----------|---------|
| `g` then `h` | Dashboard home |
| `g` then `b` | Bots |
| `g` then `t` | Tickets |
| `g` then `a` | Analytics |

## Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + S` | Save pending configuration changes |
| `Ctrl/Cmd + Enter` | Send a reply from the ticket composer |
| `Ctrl/Cmd + Z` | Undo in the embed designer |
| `Ctrl/Cmd + Shift + Z` or `Ctrl/Cmd + Y` | Redo in the embed designer |

## Command Palette

The palette jumps to dashboard pages: home, servers, bots, add bot, tickets, approvals, escalations, analytics, AI usage, MCP, billing, support, and this shortcut list. It does not search tickets.
